## Applied Machine Learning & Data Science

### Retrieval-Augmented Generation for Corporate Strategy Forecasting
**Context:** Finance / Economic Analysis  

- Built an end-to-end Retrieval-Augmented Generation (RAG) system to forecast upcoming strategic projects of publicly traded companies.
- Integrated large-scale unstructured data sources, including SEC filings (10-K, 8-K), patents, and financial news articles.
- Designed document parsing, embedding, and retrieval pipelines using vector databases to support entity-isolated inference at the firm level.
- Generated structured quantitative outputs estimating implementation costs and market value impacts, enabling downstream economic analysis.

**Keywords:** Applied ML, Financial NLP, RAG, Large-scale Text Data

---

### Large-Scale Feature Engineering and Disease Modeling (UK Biobank)
**Context:** Healthcare / Biostatistics  

- Processed high-dimensional population-scale health data with hundreds of thousands of subjects and thousands of predictors.
- Implemented robust data cleaning, missingness handling, and feature filtering pipelines for downstream disease risk modeling.
- Applied statistical learning and machine learning techniques to rank predictors and evaluate disease associations.
- Emphasized reproducibility, scalability, and interpretability in high-noise biomedical settings.

**Keywords:** Data Science, Healthcare ML, Feature Engineering, Statistical Learning

## Statistical & Research-Driven Projects

### Penalized Regression without Cross-Validation
**Context:** Statistical Modeling  

- Investigated penalized regression methods (Ridge, LASSO, Elastic Net) under privacy-preserving and summary-data constraints.
- Implemented coordinate descent–based estimation procedures and model selection strategies.
- Explored covariance-aware regression models to improve tuning parameter selection without cross-validation.
- Applied methods to neurobiological and behavioral prediction tasks.

**Keywords:** Statistics, Penalized Regression, High-Dimensional Data

---

### Diagnostic Question Analysis with Modified Item Response Theory
**Context:** Educational Data Mining  

- Developed a modified Item Response Theory (IRT) model to analyze student interaction data.
- Modeled learner proficiency and question difficulty for automated diagnostic assessment.
- Demonstrated improved prediction accuracy over baseline IRT models.
- Applied results to adaptive learning and curriculum recommendation scenarios.

**Keywords:** IRT, Statistical Modeling, Educational Data
